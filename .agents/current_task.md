# ТЗ №7: Полірування UX, живі індикатори процесів, вкладка всіх конкурентів та виправлення фото

## Мета
Усунути виявлені UX-недоліки та довести систему до фінального комерційного вигляду:
1. Додати живий індикатор прогресу (Progress Bar та покрокові стадії автопілоту) та блокування кнопок зі спінером під час виконання.
2. Додати постійний банер помилок (Error Banner) при збоях бекенду/API.
3. Додати перемикач вкладок: **«Мій каталог» (13 товарів)** та **«Всі зібрані конкуренти» (61+ оферів з Prom.ua)**.
4. Зробити клікабельним блок `+ ще N оферів` з відкриттям модального вікна з усіма конкурентами обраного товару.
5. Виправити завантаження фотографій: додати `referrerpolicy="no-referrer"`, обробку `onerror` з красивим fallback-значком і оновити базу робочими URL зображень.

## Детальні вимоги до реалізації

### 1. Бекенд `src/api/app.py`
- Додати ендпоінт для другої вкладки:
  `GET /api/competitor-offers`:
  - Повертає список усіх пропозицій з таблиці `competitor_offers`, відсортованих за часом або ID.
  - Для кожного офера повертає: `id`, `title`, `seller_name`, `price`, `url`, `image_url`, `is_in_stock`, `scraped_at`, а також назву нашого товару (якщо є зв'язка в `ProductMatch`) та статус AI-вердикту.

---

### 2. Клієнтський інтерфейс `src/web/static/index.html`

#### А. Живий індикатор процесу (Progress & Activity Banner)
- Розмістити у верхній частині робочої області (під панеллю кнопок) блок, що з'являється під час виконання дій:
  - Текст поточного кроку: наприклад, *"Крок 1/3: Збір актуальних цін з Prom.ua..."* $\rightarrow$ *"Крок 2/3: AI-зіставлення через Gemini 2.5 Flash..."* $\rightarrow$ *"Крок 3/3: Перерахунок рекомендованих цін..."*.
  - Анімований смугастий прогрес-бар (або індикатор з відсотками).
  - Під час виконання всі кнопки дій стають `disabled`, а на активній кнопці з'являється обертовий спінер `<i data-lucide="loader-2" class="animate-spin"></i>`.

#### Б. Банер критичних помилок (Error Alert)
- Якщо будь-який запит повертає помилку (мережевий збій, 500, таймаут Prom або помилка квот Gemini):
  - З'являється червона плашка з іконкою `alert-triangle`, точним текстом помилки та кнопкою «Закрити».
  - Помилка не зникає автоматично через 3 секунди, а залишається видимою, доки користувач її не закриє або не повторить спробу.

#### В. Перемикач вкладок (Tabs)
- Над таблицею додати 2 перемикачі:
  1. **Вкладка 1: «Мій каталог і репрайсинг» (лічильник: 13)** — поточна головна таблиця розрахунку цін.
  2. **Вкладка 2: «Всі зібрані конкуренти з Prom.ua» (лічильник: 61+)** — таблиця, де видно АБСОЛЮТНО ВСІ зібрані пропозиції:
     - Фото конкурента, Назва на Prom.ua, Магазин/Продавець, Ціна, Наявність («В наявності» / «Немає»), Посилання на Prom, прив'язка до нашого товару.
     - Пошук працює для обох вкладок.

#### Г. Модальне вікно всіх конкурентів для одного товару
- Зробити кнопку `+ ще N оферів` (або кнопку «Детальніше») клікабельною:
  - Відкриває модальне вікно/діалог: «Всі конкуренти для: [Назва нашого товару]».
  - Показує повний перелік усіх знайдених пропозицій (і схвалених, і відхилених, і тих, де товару немає в наявності) з розгорнутим поясненням Gemini AI для кожного.

#### Д. Виправлення фотографій (Image Fallback & Attributes)
- Додати до всіх тегів `<img>` атрибут:
  `referrerpolicy="no-referrer"`
- Додати безпечний обробник помилки завантаження:
  ```html
  <img src="${p.image_url}" referrerpolicy="no-referrer" onerror="this.classList.add('hidden'); this.nextElementSibling.classList.remove('hidden');" class="w-full h-full object-cover">
  <div class="hidden w-full h-full flex items-center justify-center bg-slate-800 text-slate-400">
    <i data-lucide="package" class="w-5 h-5"></i>
  </div>
  ```
  Це гарантує, що замість зламаного браузерного квадрата з налізлим текстом завжди буде відображатися акуратна іконка або реальне фото!

---

### 3. Оновлення реальних фотографій
- Створити скрипт `scripts/update_images.py`, який:
  - Для кожного товару в `products` підставляє реальне робоче посилання на фотографію товару (взявши робочі URL із уже зібраних `competitor_offers` на Prom.ua).
  - Оновлює `prom_feed.xml`, замінивши фіктивні `1001_baseus...` на робочі посилання.

## Критерії приймання та верифікація (Verification)
1. Запуск скрипта оновлення фотографій:
   ```bash
   venv/bin/python scripts/update_images.py
   ```
   *Очікуваний результат:* у базі даних товари отримали реальні робочі посилання на зображення.
2. Перевірка нового ендпоінту:
   ```bash
   venv/bin/python -c "from src.api.app import app; from fastapi.testclient import TestClient; client = TestClient(app); res = client.get('/api/competitor-offers'); print('Total offers via API:', len(res.json())); assert len(res.json()) > 0"
   ```
   *Очікуваний результат:* повертає 61+ записів оферів конкурентів зі статусом 200.
3. Відкриття сайту в браузері:
   - Присутній робочий перемикач вкладок («Каталог» / «Зібрані конкуренти»).
   - Клік на `+ ще N оферів` відкриває модальне вікно з повним списком оферів.
   - Фотографії відображаються коректно (без зламаних значків).
   - При натисканні дій видно живий індикатор виконання та блокування кнопок.
